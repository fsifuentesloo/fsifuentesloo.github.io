## 🛠️ Featured Treasury Projects

### 1. Global Bulk Payment Automation & Control Framework
*   **Account Scope:** Citi-US-USD Corporate Account
*   **Objective:** Eliminate manual transaction entry, secure cash outbound workflows, and standardize batch processing.

#### ⚠️ The Challenge
*   **Manual Bottlenecks:** Treasury operations required the manual execution of dozens of individual transaction requests monthly.
*   **Operational Risk:** Manual data entry into banking portals increased exposure to human error, typos, or processing delays.
*   **Audit Fragility:** Fragmented transactional trails made end-to-end tracing slow and labor-intensive.

#### 🛠️ The Solution
*   **Data Consolidation Engine:** Programmed a secure macro solution to automatically aggregate, clean, and format payment requests from a standardized Treasury template.
*   **Pre-Transmission Validation:** Built data-integrity verification into the script logic to validate beneficiary bank account details prior to banking portal upload.
*   **Batch File Generation:** Automated the output of secure, bank-compliant bulk payment files seamlessly accepted by Citi for batch processing.

#### 📈 Business Impact
*   **Efficiency:** Reduced payment processing windows from hours of individual entries down to an automated batch upload completed in minutes.
*   **Risk Mitigation:** Achieved a near-zero operational error rate by enforcing programmatic pre-validation on all beneficiary records.
*   **Strengthened Controls:** Standardized the workflow, providing internal and external auditors with an exact, tamper-proof trace from data source to bank execution.

#### 🛠️ The Solution
*   **Treasury Dashboard Integration:** Developed a centralized treasury dashboard to capture transaction values, liquidity data, and execution dates seamlessly.
*   **Automated Core Tracking:** Integrated customized macros to instantly ingest, reconcile, and display customer refunds and internal transactions.

#### 📈 Business Impact
*   **Real-Time Cash Positioning:** Transformed slow, reactive data compilation into a highly dynamic liquidity monitoring tool.
*   **Fluid Bank-Subsidiary Communication:** Established a standardized verification flow, creating an optimal data loop between corporate treasury, internal subsidiaries, and partner banks.
